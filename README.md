# Проект для тестирования API с использованием Python, pytest и requests

## Описание проекта

Этот проект представляет собой набор тестов для API, доступного по адресу https://jsonplaceholder.typicode.com/
Проект включает в себя позитивные и негативные тесты для операций с постами и комментариями:
создание, обновление, удаление постов, а также получение комментариев к постам.

# Тестирование реализовано с помощью библиотеки `pytest` и `requests`.

## Установка зависимостей

Для установки всех зависимостей, используемых в проекте, выполните следующую команду:

```bash
pip install -r requirements.txt
```

В файле requirements.txt указаны следующие зависимости:

```
requests==2.32.3

pytest==8.3.3

allure-python-commons
```

## Описание файлов:

`data.py` — содержит набор тестовых данных для создания и обновления постов.

`urls.py` — хранит URL-адреса для тестируемых эндпоинтов.

`test_create.py` — тесты для создания постов с использованием различных валидных и невалидных данных.

`test_update.py` — тесты для обновления постов с использованием различных валидных и невалидных данных.

`test_comments.py` — тесты для получения комментариев к постам.

### Реализованные сценарии

#### Проверка создания поста 
Проверка успешного создания поста с валидными данными
Проверка создания поста с невалидными данными:

    - пустой Json
    - отсутствующая строка title,body,userId
    - числовой формат title, body
    - строковый формат userId
    - булевы значения в title, body, userId
    - значения null в title, body, userId
    - несуществующий userId


#### Проверка обновления поста
Проверка успешного обновления поста с валидными данными
Проверка обновления поста с невалидными данными:

    - пустой Json
    - отсутствующая строка id, title,body,userId
    - числовой формат title, body
    - строковый формат id, userId
    - булевы значения в id, title, body, userId
    - значения null в id, title, body, userId
    - несуществующий id, userId


#### Успешное удаление поста
Успешное удаление поста с валидным id поста

#### Успешное удаление поста
Успешное получение списка комментариев к посту
Проверка получения списка комментариев к посту с несущестующим id поста
